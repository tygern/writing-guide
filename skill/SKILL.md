# Tyson's writing guide

Read [the complete guide](references/guide.md) before drafting, editing, or reviewing. If it cannot be read, report the access problem instead of claiming to apply it. Follow the user's requested scope and the guide's priorities.

Use the guide's drafting, editing, or review instructions according to the request. Do not add a review report to a prose-only task. Preserve factual scope, uncertainty, and supported personal experience.

For difficult sentence edits, consult [sentence examples](references/sentence-edits.md). For paragraph structure and voice, consult [annotated published excerpts](references/annotated-passages.md). The examples illustrate the guide; they do not override it. Do not read evaluation cases as writing instructions.

Check the result against the guide before delivering it. Loading the guide does not establish that the output complies with every rule.
